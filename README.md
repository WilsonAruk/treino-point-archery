Treino Point Archery
Site de treino físico para tiro com arco, separado por tipo de arco (Recurvo Olímpico, Composto, Barebow/Tradicional e Preparação Física), com vídeos de referência no YouTube.
Funcionalidades
Escolha do tipo de arco e lista dos treinos mais assistidos daquele arco
Busca dentro do arco escolhido
Séries e repetições sugeridas para cada treino, com botão para assistir no YouTube
Adicionar novos treinos colando um link do YouTube
Layout responsivo (celular e computador)
⚠️ Aviso
Os treinos são apenas sugestões. Procure sempre um profissional especializado antes de começar e pare o exercício imediatamente se sentir dor.
Como usar
Abra o `index.html` no navegador ou acesse a versão publicada pelo GitHub Pages.
> O ranking de "mais assistidos" e os treinos adicionados ficam salvos no navegador de cada usuário.
